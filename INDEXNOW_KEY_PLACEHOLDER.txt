IndexNow setup for Bing (and Yandex)
====================================

IndexNow lets you instantly notify Bing when pages are added or updated,
speeding up indexing.

Steps:
1. Generate a key (a hex string, 8-128 chars) at https://www.bing.com/indexnow
   or use any UUID/random hex string.
2. Create a file named <yourkey>.txt at the site root whose ONLY contents
   are the key itself, e.g.:
       https://www.gravelcalculator.ca/ab12cd34ef56....txt
   (rename this placeholder file to <yourkey>.txt and put the key inside it)
3. Ping IndexNow whenever you publish/update a URL:
       https://www.bing.com/indexnow?url=https://www.gravelcalculator.ca/&key=<yourkey>
   or POST a JSON list of URLs to https://api.indexnow.org/indexnow

This file is a placeholder/instruction only — delete it once your real
<yourkey>.txt is in place.
