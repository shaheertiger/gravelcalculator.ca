How to choose a gravel calculator

Start with the main gravel calculator for any project. If you order by the cubic yard, use the cubic yards calculator; if you order by weight, use the tonnage calculator. For specific jobs, the driveway, patio, pea gravel, crushed gravel and French drain calculators come preset with the right depth and density. There's also an aquarium gravel calculator for fish tanks and a French-language version.

Frequently asked questions

Which gravel calculator should I use?

Use the main gravel calculator for any project. For specific jobs, pick the matching tool — driveway, patio, pea gravel, crushed stone, French drain, aquarium — which comes preset with sensible defaults. Use the cubic yards or tonnage calculators if you order by yardage or weight.

Are all the calculators free?

Yes. Every calculator on GravelCalculator.ca is free, works in metric and imperial units, and runs entirely in your browser — nothing is stored.

Do the calculators include cost?

Yes. Each tool has an optional price field so you can estimate the material cost in Canadian dollars per tonne, kilogram, cubic metre or cubic yard.

Disclaimer: All results are estimates. Actual gravel quantities vary with type, particle size, moisture and compaction. Costs cover material only and exclude labour, delivery and taxes.
